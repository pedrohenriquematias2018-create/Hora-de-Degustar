# 🍪 Hora de Degustar

Aplicativo mobile desenvolvido em **React Native** com **Expo** e estilizado com **NativeWind (Tailwind CSS)**. O app funciona como um cardápio digital interativo de cookies artesanais, contando com busca inteligente, filtro por categorias, carrinho de compras e envio direto do pedido formatado para o WhatsApp.

## 🚀 Funcionalidades
- 🔍 **Busca em tempo real** com normalização de acentos e letras maiúsculas/minúsculas.
- 🏷️ **Filtro por categorias** (Clássicos, Recheados, Especiais).
- 🛒 **Carrinho dinâmico** com adição/remoção de itens e cálculo automático do valor total.
- 📱 **Integração com WhatsApp** para finalizar e enviar o pedido com um clique.

## 🛠️ Tecnologias Utilizadas
- React Native
- Expo
- TypeScript
- NativeWind (Tailwind CSS)
